Chạy trực tiếp qua PowerShell

Cách chạy (giống tool MAS):
1. Lệnh bên dưới đã được tự động Copy.
2. Nhấn chuột phải vào nút Start Windows → chọn Terminal hoặc PowerShell.
3. Nhấn Ctrl + V rồi nhấn Enter để chạy ngay!
Nguồn GitHub:

3/ Menu boot của Grub4EFI

⚠ Lưu ý: File .WIM cần có module ntloader đặt trong \EFI\grub\ để Grub4EFI nạp trực tiếp.

4/ Kiểm tra & Chạy thử kết quả đã cài

1. Kiểm tra UEFI NVRAM / BCD
2. Kiểm tra Secure Boot
3. Quét file ISO/VHD trong menu.lst
4. Boot thử file EFI thật trên QEMU
Chạy kiểm chứng ngay sau khi cài Mục 1 hoặc Mục 3:
Lệnh bên dưới đã được tự động Copy — dán vào PowerShell và nhấn Enter để đọc trực tiếp \EFI\grub\grub4efi.efi và menu.lst vừa cài rồi mở cửa sổ máy ảo QEMU xem kết quả!
